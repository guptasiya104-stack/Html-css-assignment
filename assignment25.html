🎨 Short Note on Design Choices

1. Font Pairing: I used Poppins (700, 600) for all headings - it looks bold and professional. For body text, I used Inter (400, 500) because it is very clean and easy to read on mobile. This is a popular pairing used by many professional websites.

2. Colour Palette: I chose a professional palette: Primary #0f172a (Slate - Header) Accent #2563eb (Blue - Links) Background #f8fafc (Light Grey) Surface #ffffff This palette has good contrast and is not too bright.

3. Design Tokens (Assignment 24): I created CSS variables in :root like --color-primary, --text-lg, --space-lg. This makes it easy to change design in one place and keeps consistency across all 4 pages.

4. Layout: Used simple cards with 12px radius, 1px border, soft shadow. Sticky navigation for easy switching. Mobile responsive with grid that becomes 1 column on small screens.

5. Consistency: All pages (Home, About, Registration, Contact) use same nav, same colours, same fonts, same card style - so user feels it's one website, not 4 different pages.
