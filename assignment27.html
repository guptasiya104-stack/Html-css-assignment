Three Card Variants

Assignment 27 | Siya Gupta | Using border-radius & backgrounds | 7895673750

VARIANT 1

Small Radius + Solid BG

border-radius: 8px;
background: #ffffff (solid white)
border: 1px solid #e2e8f0
Use: Clean, professional cards for forms, info

  • 8px - subtle rounded corners
  • Solid background
  • Light shadow
VARIANT 2

Large Radius + Gradient BG

border-radius: 24px;
background: linear-gradient(135deg, #2563eb, #7c3aed)
Use: Hero cards, premium, CTA cards

  • 24px - very rounded, soft
  • Gradient background
  • White text
VARIANT 3

Asymmetric Radius + Pattern BG

border-radius: 16px 2px 16px 2px;
background: pattern dots + #fffbeb
border: 2px dashed #f59e0b
Use: Fun, creative, notice cards

  • 16px 2px 16px 2px - asymmetric
  • Pattern background (dots)
  • Dashed border

Code Explanation for Teacher:

/* V1 */ .card-1{ border-radius:8px; background:#fff; }
/* V2 */ .card-2{ border-radius:24px; background:linear-gradient(135deg, #2563eb, #7c3aed); }
/* V3 */ .card-3{ border-radius:16px 2px 16px 2px; background-image:radial-gradient(...) + #fffbeb; }
