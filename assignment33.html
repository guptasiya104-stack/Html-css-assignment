Code used:
.product-list{
  display:flex;
  flex-wrap:wrap; /* wraps items to next line */
  gap:16px;
  justify-content:center;
}
.product-card{
  flex: 1 1 220px; /* grow=1, shrink=1, basis=220px */
  max-width:240px;
}

Flex-wrap se products automatically next line me chale jate hain, screen chhota hone par 4 se 2 se 1 column ho jata hai. No media query needed for wrapping, only for full width on very small screen.
