My Own Element - Screenshot Annotation

I inspected my .box-element card from my multi-page project using Chrome DevTools. Below is the visual explanation + annotation.

CONTENT AREA
Width: 100% | Height: auto
This is actual text/content
background: white, border: green
CONTENT - White + Green Border PADDING (25px) - Light Blue BORDER (10px solid #2563eb) MARGIN (20px) - Light Red + Dashed
1. Content (Innermost): The white box with green border. This is where text, image sits. Size controlled by width/height.
2. Padding (25px): Light blue area between content and border. It gives breathing space inside. I used padding:25px;
3. Border (10px solid blue): The thick blue line around padding. It is visible. I used border:10px solid #2563eb;
4. Margin (20px): Outer light red dashed area. Space OUTSIDE border to push other elements away. I used margin from wrapper 20px.

Total Size Calculation: Total Width = Content Width + Padding (25*2) + Border (10*2) + Margin (20*2)
If content is 300px, then total = 300 + 50 + 20 + 40 = 410px

  2. Right click on my card element -> Inspect
  3. In Elements tab, select the element
  4. In Styles pane, see Computed -> Box Model diagram at bottom
  5. Take screenshot with Snipping Tool - it shows Content / Padding / Border / Margin values
