Responsive Menu Bar using display:flex

Assignment 31 | Siya Gupta | BCA 1st Year | Invertis University

Desktop: Logo left, links center, button right - all in one row using display:flex; justify-content:space-between; align-items:center;

Mobile (650px se kam): Menu hamburger (☰) pe click karne par links vertically stack ho jate hain using flex-direction:column; and flex-wrap:wrap;

.navbar{
  display: flex;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
}
.nav-links{
  display: flex;
  gap: 18px;
}
@media(max-width:650px){
  .nav-links{ flex-direction: column; width:100%; }
}

Test: Browser window ko chhota karke dekho - menu responsive ho jayega, mobile me ☰ icon ayega.
