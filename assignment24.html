1. Colour Tokens (CSS Variables)

We defined colours in :root and reused everywhere with var(--color-*)

--color-primary: #0f172a --color-accent: #2563eb --color-accent-light: #dbeafe --color-bg: #f8fafc --color-success: #16a34a

2. Font Size Tokens

--text-xs: 11px - Extra Small (like this)

--text-sm: 13px - Small

--text-base: 15px - Base (normal text)

--text-lg: 18px - Large (H2)

--text-xl: 22px - XL

--text-2xl: 28px - 2XL (Main Heading)

3. Spacing & Radius Tokens

--space-sm: 8px, --space-md: 16px, --space-lg: 24px
--radius-sm: 8px, --radius-md: 12px, --radius-lg: 16px

If we change value in :root, it changes everywhere automatically. That's the power of design tokens!

Example: This box uses var(--space-sm), var(--radius-sm), var(--color-accent-light) tokens.

Why Design Tokens?

1. One place to change colours/sizes
2. Consistent design
3. Easy dark mode later
4. Professional workflow used in companies
