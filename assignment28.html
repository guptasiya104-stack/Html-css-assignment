Summary of All Fixes I Applied:

  1. * { box-sizing:border-box; } - Padding doesn't add extra width
  2. body { overflow-x:hidden; } - Prevents horizontal scroll bar
  3. img, video { max-width:100%; height:auto; } - Media never overflow container
  4. overflow-wrap: break-word; word-break: break-word; - Breaks long URLs/words
  5. .pre, code { overflow-x:auto; white-space:pre-wrap; } - Code scrolls inside, not page
  6. flex items { min-width:0; } - Allows flex child to shrink
