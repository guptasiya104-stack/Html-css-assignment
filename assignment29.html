Position & Z-Index Explanation (Teacher ke liye):

.hero { position: relative; } /* parent context */
.hero-bg { position: absolute; top:0; left:0; width:100%; height:100%; z-index:1; } /* background layer */
.hero-overlay { position: absolute; z-index:2; } /* gradient over image */
.blob { position: absolute; z-index:2; } /* decorative */
.hero-content { position: relative; z-index:3; } /* text on top of overlay */
.floating-badge { position: absolute; z-index:4; } /* highest, floating */
nav { position: absolute; z-index:5; } /* nav always top */

Why use z-index? Without z-index, all layers would be random. With z-index, we control stacking: 1=bg image, 2=overlay/blobs, 3=content, 4=badge, 5=nav.
